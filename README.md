# Preliminary Grade Vacancy Map

Interactive map of the Ministry of Health preliminary grade vacancy list (draft, October/November 2026, 1,300 posts).

**Live site:** https://yasikahivin.github.io/preliminary-grade-vacancy-map/

Filter by vacancy type, province, RDHS, institution level and post group, or sort stations by distance from a chosen district.

The whole app is one self-contained file, [`index.html`](index.html). It loads Leaflet from cdnjs and fonts from Google Fonts; there is no build step.

> Built from a draft list. Check final postings against the official Ministry of Health release.
